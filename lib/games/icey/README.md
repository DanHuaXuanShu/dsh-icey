# lib/games/icey/ —— ICEY 专用层

这里放**只对 ICEY 成立**的知识。换游戏时这一层要重写，但 `lib/ui/` 不用动。

## 该放什么

| 文件 | 管什么 |
|---|---|
| `layout.mjs` | 画面布局与阈值：HUD 在哪、提示框在哪、多亮算亮、菜单判据 |
| （待搬）`combos` | 招式表：磁阱 `jjiii`、迭影 `jjji`… |
| （待搬）`upgrades` | 强化树 20 个节点、功能位排序 |
| （待搬）`bestiary` | 怪物类型与对应打法 |

## 依赖方向（单向，不许反过来）

```
games/icey/  ──依赖──▶  ui/  ──依赖──▶  无
```

`ui/` 里**不许**出现 `games/`。selfcheck 有一条断言在检这件事。

## 怎么判断一段代码该放哪

问一句：**换个游戏还成立吗？**

- 「血条在左上角 3%~32% × 8%~20%」→ 不成立，放这里
- 「暗块 + 内部白色笔画 = 键帽图标」→ 成立，放 `ui/`
- 「磁阱按 J J I I I」→ 不成立，放这里
- 「屏幕下方中间的白字是旁白」→ 大半成立（横版游戏通例），但具体区域要调 ⇒
  区域放这里，判定逻辑放 `ui/`
